# 复盘反哺

每次复盘产出的新信号，必须回写阈值表，不许只留在复盘文件里。

## 流程

1. **回顾**：这次工作做了什么，遇到什么问题
2. **归因**：问题的根本原因是什么（区分真瓶颈与误判）
3. **新信号**：是否发现新的撑不住信号
4. **回写**：新信号写入 `治理/阈值登记.md`，带日期、实测值、判定
5. **改进措施**：具体怎么改，谁负责，何时复核

## 规则

- 新信号必须回写阈值表，带日期、实测值、判定
- 复盘文件与阈值表互为分工：复盘记过程，阈值表记信号
- 改进措施必须可执行、可验证、有负责人、有复核日期
- 反哺优先：每次复盘产出的新信号，必须回写阈值表，不许只留在复盘文件里

## 产出物

- `复盘/YYYY-MM-DD-<主题>.md`
- 更新 `治理/阈值登记.md`（如有新信号）

## 反模式

- **只复盘不回写**：新信号留在复盘文件里，阈值表不更新
- **无改进措施**：复盘完就完了，没有具体行动
- **无复核日期**：改进措施没有复核时间点
- **归因错误**：把 A 瓶颈误判为 B 瓶颈，必须实测验证归因
