# 权威源台账

每次写入数据前，必须查台账确认三件事：

1. **主拷贝在哪**：数据应该写到哪个绝对路径
2. **派生方向**：是否有派生拷贝，复制方向是什么（单向/双向）
3. **一致性级别**：强一致 / 最终一致 / 不适用

## 规则

- 写入只进主拷贝，不得直接写派生拷贝
- 派生拷贝单向对账，禁止反向修正主拷贝
- 四项必填字段缺一即阻塞：数据类、主拷贝位置、派生拷贝及方向、一致性级别
- 一致性级别只用三档：强一致、最终一致、不适用（单拷贝）

## 反模式

- **直接写派生拷贝**：如直接改 data.json 而不改主文档
- **反向同步**：从看板回写源文档
- **无台账写入**：新数据类未登记就写入
